This document describes the Recognized Entities Vocabulary 1.0, i.e., the RDFS [[rdf-schema]] defined by the [[[?vc-recognized-entities-1.0]]] [[?vc-recognized-entities-1.0]] specification..

Alternate versions of the vocabulary definition exist in Turtle and JSON-LD.

Published:
2026-09-02
Version Info:
1.0
See Also: https://www.w3.org/TR/vc-recognized-entities-1.0/

This vocabulary has been defined by the W3C Verifiable Credentials Working Group and provides the official RDFS vocabulary for Recognized Entities 1.0 specification. Comments regarding this document are welcome. Please file issues directly on GitHub, or send them to public-vc-comments@w3.org (subscribe, archives).

    Class definitions

    The following are class definitions in the re namespace.

    RecognizedEntity

    Recognized Entity

    See the formal definition of the term.

    An entity that is recognized an Recognized Entity Credential to perform a specific action.
    Range of:
    credentialSubject
    Domain of:
    recognizedTo, recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    RecognizedAction

    Recognized Action

    See the formal definition of the term.

    An action that a Recognized Entity is expected to perform.
    Range of:
    recognizedTo
    Domain of:
    action, recognizedBy, outputValidation
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    RecognizedEntityCredential

    Recognized Entity Credential

    See the formal definition of the term.

    A conforming verifiable credential, as defined in [[[?vc-data-model-2.0]]], that encapsulates Recognized Entities entities.
    Subclass of:
    cred:VerifiableCredential
    Range of:
    recognizedBy
    Includes the range of:
    recognizedIn
    Domain of:
    credentialSubject
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    x509CertificateAuthorityList

    X509 certificate authoring list

    See the formal definition of the term.

    This is mainly a placeholder to keep the vocabulary together, those lists are usually not defined in RDF terminologies
    Includes the range of:
    recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    EtsiTrustServiceList

    ETSI Trust Service list

    See the formal definition of the term.

    This is mainly a placeholder to keep the vocabulary together, those lists are usually not defined in RDF terminologies
    Includes the range of:
    recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    Property definitions

    The following are property definitions in the re namespace.

    action

    Action

    See the formal definition of the term.

    Name of the action to be performed by a Recognized Entity. Possible values include "issue" or "verify".
    Domain:
    RecognizedAction
    Range:
    xsd:string
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    recognizedBy

    Recognized by

    See the formal definition of the term.

    The Recognized Entity Credential that performed the task of recognizing.
    Domain:
    RecognizedAction
    Range:
    RecognizedEntityCredential
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    outputValidation

    Output validation

    See the formal definition of the term.

    Refers to a data schema that provides verifiers with enough information to determine whether the provided data conforms to the provided schema (e.g., JSON Schema).

    The property's value should be a URL, i.e., not a literal.
    Domain:
    RecognizedAction
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    recognizedTo

    Recognized to

    See the formal definition of the term.

    Refer to the Recognized Action.
    Domain:
    RecognizedEntity
    Range:
    RecognizedAction
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    recognizedIn

    Recognized in

    See the formal definition of the term.

    Refer to the Recognized Action.
    Domain:
    RecognizedEntity
    Range:
    EtsiTrustServiceList ⊔ x509CertificateAuthorityList ⊔ RecognizedEntityCredential
    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    validFrom

    Valid from

    The beginning of the validity for claims.

    This term is formally defined in another vocabulary (as cred:validFrom), but is frequently used with this vocabulary and has been included to aid readability of this document.

    validUntil

    Valid until

    The end of the validity for claims.

    This term is formally defined in another vocabulary (as cred:validUntil), but is frequently used with this vocabulary and has been included to aid readability of this document.

    credentialSubject

    Credential subject for recognized entities

    See the formal definition of the term.

    When used in a recognized entity credential, the value must be restricted to recognized entities.
    Subproperty of:
    cred:credentialSubject
    Domain:
    RecognizedEntityCredential
    Range:
    RecognizedEntity

    name

    name

    name of an entity

    This term is formally defined in another vocabulary (as schema:name), but is frequently used with this vocabulary and has been included to aid readability of this document.

    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1

    digestMultibase

    Digest Multibase

    One or more cryptographic digests used to verify the integrity of resources associated with the entity.

    This term is formally defined in another vocabulary (as sec:digestMultibase), but is frequently used with this vocabulary and has been included to aid readability of this document.

    Relevant @context:
    https://www.w3.org/ns/credentials/recognizedEntities/v1
